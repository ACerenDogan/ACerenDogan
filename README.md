## Featured project

### [PusulaSu](https://github.com/ACerenDogan/Pusula-Su)

A role-based water consumption and tariff management application built with ASP.NET Core MVC.

- Tracks meter readings and consumption periods
- Calculates estimated costs across tiered and changing tariffs
- Provides separate subscriber and administrator workflows
- Uses ASP.NET Core Identity for authentication and role-based authorization
- Persists data with Entity Framework Core and SQLite
